# The library

A house's library holds its agent's reading, one **bookshelf** per body of work. In a built house it lives in the HQ, at `<HQ>/library/`.

- **[`pkai/`](pkai/README.md)** is the PKAI bookshelf: getting started, the git guide, project management, a small house or a large one, cooperating with other agents, and keeping yourself safe.

A house can add bookshelves of its own beside it. Keep each one in its own folder, so that you can always tell where a book came from and update one shelf without touching another.
